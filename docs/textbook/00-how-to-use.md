# 第 0 章 如何使用本书与实验室

这一章不引入新的物理。它说明教材与实验室怎样配合：文字负责把一个问题讲清楚，交互图让你在同一个量子态上
亲手检验；它也说明公开教材站上的实验室能显示什么、不能显示什么，以及什么时候应该在本地运行实时计算版。

## 学习目标 {#goals}

读完本章，你应当能够：

- 说出本书每一部分分别回答什么问题；
- 分清“量子态 / observable / representation”三层，并知道实验室的控件怎样对应这三层；
- 使用每张交互图上的“加载交互图”和“在实验室中打开”；
- 知道教材站上的实验室能显示哪些场景，以及什么时候需要在本地运行 `quviz serve`。

## 阅读路线 {#reading-path}

预备知识是微积分、复数，以及线性代数中“基与基之间的幺正变换”。量子力学的其余概念都在用到时引入。

全书分四个阶段：

1. 第 1–3 章回答“态是什么”：波函数与 Born 规则、量子数与能级、径向分布与节点；
2. 第 4–7 章回答“怎样画出一个态”：基的选择、电子云、等值面、相位与平面切片；
3. 第 8–9 章回答“概率怎样流动、何时随时间变化”：概率流、叠加态与时间演化；
4. 第 10–11 章回答“图与实验、化学是什么关系”：从密度到实验图样、对称性与杂化。

附录 A 汇总各章的常见误区；附录 B 列出单位、坐标约定和深链接的写法。

## 实验室导览 {#lab-tour}

实验室是一块铺满屏幕的三维画布，所有控件都是浮在画布上的半透明面板。

- **画布**：背景是中性的深灰色，$z$ 轴朝上，所以 $2p_z$ 的两瓣上下排列，与教科书插图一致；左下角有坐标轴指示。
  按住鼠标拖动可以旋转视角，滚动滚轮可以缩放。
- **顶栏**：左侧是 QuViz 标志和一枚「教学预览」药丸标签；右侧是 教材 · 复制链接 · 保存图像 · 指南 · GitHub
  五个按钮。在本地实时版里，药丸标签显示「实时计算」，「查看 OpenAPI」取代「教材」按钮。
- **左侧的控制面板**可以收起成一个圆形的「调节」按钮，展开时分三组：
    - 「量子态」选择本征态或叠加态，以及量子数和基，这是“量子态”这一层；
    - 「表示法」选择画法（电子云、等密度面、平面切片、概率流线）和它的参数，这是 representation 这一层；
      平面切片还要在这里选择平面和要画的场，也就是 observable（这里取宽义：除 $\lvert\psi\rvert^2$ 外，
      $\operatorname{Re}\psi$、$\operatorname{Im}\psi$ 与 $\arg\psi$ 会随全局相位改变，只是由态导出的场，见第 1 章）；
    - 「显示」不属于这三层，只调整观感，例如点的大小、透明度和地面网格，不改变任何物理量。
- **底部的时间胶囊**说明时间在当前场景里扮演什么角色：
    - 本征态显示「定态 · $\lvert\psi\rvert^2$ 与 $t$ 无关」，没有可播放的演化；
    - 能量不同的叠加态会振荡，胶囊提供逐帧步进和播放，并显示振荡周期和当前帧的序号；
    - 能量简并的叠加态显示「能量简并：密度不随时间变化」。
- **右侧的详情面板**有 概览 / 图表 / 场景契约 / 引用 四个标签页。「图表」页对本征态画出径向分布 $P(r)$ 和能级梯，
  对叠加态画出各项的权重 $\lvert c_k\rvert^2$ 以及由能级差决定的拍周期。
- **右上角的「查找量子态」**按名称搜索预设和目录中的全部量子态，例如输入 2p 或 3d。
- **右下角的图例胶囊**说明当前画面中颜色的含义。**颜色的含义只以图例为准**：同一种颜色在电子云、切片和流线里
  可能代表完全不同的量。
- **「指南」弹窗**集中介绍界面与读图方法，分为 概览 / 读图指南 / 教材章节 三个标签页。
- 在宽度不超过 820px 的屏幕上，控制面板和详情面板改为从底部拉出的抽屉。

## 交互图怎么用 {#figures}

本书的每张交互图都是一张卡片，带有图注和两个按钮。

- **加载交互图**：在页面内运行实验室的嵌入模式。嵌入模式只保留画布、图例胶囊、时间胶囊、一条状态提示和一个
  「在实验室中打开」链接，其余面板都隐藏，方便你专注于这一张图。
- **一次只运行一张**：同一页面同时只运行一个交互图，加载另一张时，前一张会自动关闭；看完后也可以点
  「关闭交互图」主动释放它。
- **在实验室中打开**：在新标签页打开完整的实验室，状态与这张图相同。地址栏里 `#` 之后的部分，例如
  `#mode=eigenstate&n=2&l=1&m=0&basis=real&rep=point_cloud`，就是这个状态的**深链接**。它记录量子态、表示法、
  切片的平面与场，叠加态暂停时还记录当前时刻 $t$（播放时不写入 $t$）；把带有它的完整地址发给别人，对方打开的就是同一个场景。
  视角不写入深链接；在本地实时版里，样本数、网格、包围概率等可调参数也不写入，对方看到的是它们的默认值。
  顶栏的「复制链接」复制的就是带有深链接的完整地址。深链接中每个键的含义见附录 B。
- 实验室需要浏览器支持 WebGL。浏览器不运行 JavaScript 时，交互图不可用，但图注仍然作为普通图注显示，可以照常阅读。

## 教材版与本地实时版 {#static-and-live}

公开教材站上的实验室没有后端服务器，它只能显示构建教材时预先计算好的场景目录：

- $Z=1$（氢原子）时 $n\le4$ 的全部本征态，实基与复基各一套；
- 电子云：每个态 28,000 个样本点，随机种子为 7；
- 等密度面：包围 90 % 概率的曲面，计算网格由目录固定，实际使用的网格写在「场景契约」标签页里。3s 与 4s
  的等密度面即使在本地也会被拒绝：它们的径向节点需要超过当前网格上限的分辨率，实验室会显示这条原因；
- 平面切片：xy、xz、yz 三个平面上的 $\lvert\psi\rvert^2$、$\operatorname{Re}\psi$、$\operatorname{Im}\psi$
  与 $\arg\psi$ 四种场；
- 概率流线：复基中 $m\ne0$ 的本征态，流线种子数为 48；
- 四个叠加态预设 $1s+2p_z$、$2s+2p_z$、$1s+3d_{z^2}$、$2p_{+1}+2p_{-1}$ 的等密度面、概率流线和 xz 切片，
  时间取播放器的各帧。两个能量简并的预设（$2s+2p_z$ 与 $2p_{+1}+2p_{-1}$）密度不随时间变化，只存 $t=0$ 一帧。

在教材版里，样本数、随机种子、网格、包围概率、流线种子数和 $Z$ 都固定为目录中的值，只能查看，不能修改。

超出目录的组合会被标成「未预计算」。实验室给出的原因总以下面这句话开头：

「静态教材版未预计算这一组合。本地运行 quviz serve 可实时计算任意参数。」

如果碰到的是目录的某条限制，例如 $n\le4$ 或 $Z=1$，后面还会再用一句话点明这条限制。

另一类情况是计算本身的拒绝。构建教材时，服务端对少数组合给出了带原因的拒绝，例如网格在上限内无法收敛；
这些原因被原样保存，实验室照原样显示。

在本地，`quviz serve` 会对经过验证的参数范围内的任意组合实时计算，包括其他的 $n$、$Z$、样本数和包围概率；
在本地构建的这套教材里，交互图连接的是本机 8000 端口上运行的 `quviz serve`，而且要先构建前端（`web/dist`），
否则那里只有 API，没有实验室页面。安装与启动方法见[安装](../getting-started/installation.md)。

## 读图的三条规则 {#reading-rules}

实验室和本书都遵守下面三条原则，读每一张图时都值得对照一遍：

1. **物理对象不等于画法。** 概率密度 `probability_density` 是一个 observable；等密度面只是把它画出来的一种
   representation。换一种画法，被画的量并没有变。
2. **约定可以追溯。** 长度单位 bohr、能量单位 hartree（Ha）、所用的基、归一化方式和等密度面实际包围的概率，
   都写在详情面板里；其中坐标约定、归一化、长度单位和包围概率集中在「场景契约」标签页。两张图能否直接比较，先看这里。
3. **好看不能失真。** 颜色编码的是数据，不是装饰，颜色的含义以图例为准。透明度、光晕和相机运动只能帮助阅读，
   不能改变节点、尺度关系或概率的含义。

## 常见误区 {#misconceptions}

!!! warning "误区：切换表示法会换一个量子态"

    不会。表示法只决定怎样画；量子数、基和叠加系数都在「量子态」组里，切换表示法时它们保持不变。
    画面变了，被画的态没有变。

!!! warning "误区：显示「未预计算」说明这个态在物理上不存在"

    不是。「未预计算」只说明教材站的预计算目录没有收录这个组合。只要参数在经过验证的范围内，
    本地运行 `quviz serve` 就能实时计算同一个态。

!!! warning "误区：颜色越亮说明电子或电荷越多"

    颜色的含义取决于表示法，必须看图例。在电子云里，点的颜色表示波函数的相位，点的疏密才反映概率密度；
    在概率密度切片里，颜色随 $\lvert\psi\rvert$ 单调变亮；在概率流线里，颜色表示流速的大小。

## 思考题 {#exercises}

??? question "思考题 0.1：把表示法从电子云切换到等密度面，量子态变了吗？"

    没有变。$n,\ell,m$ 和基都没有改变，变的只是同一个 $\lvert\psi\rvert^2$ 的画法：电子云用随机样本在空间中的
    疏密表现概率密度；等密度面画的是曲面 $\lvert\psi\rvert^2=c$，在教材版中常数 $c$ 取得使区域
    $\lvert\psi\rvert^2\ge c$ 包含 90 % 的概率。

??? question "思考题 0.2：在教材版实验室里，为什么不能把点云样本数从 28,000 改成 50,000？"

    教材站没有后端，每一种参数组合都对应一份预先计算好的响应，而目录把样本数固定为 28,000。
    想用别的样本数，请在本地运行 `quviz serve`。

??? question "思考题 0.3：为什么同一页面同时只保留一个交互图？"

    每张交互图都是一个独立的实验室页面，各自持有一个 WebGL 上下文和相应的显存，而浏览器能同时保持存活的
    WebGL 上下文数量是有限的。先关掉旧的再加载新的，可以避免浏览器自行回收某个上下文，让已经打开的图突然失效。
