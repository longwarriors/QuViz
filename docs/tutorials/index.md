5. [点群与轨道杂化](hybridization.md)：当前固定的 $sp^3$ 变换与后续边界；

如果目标是先把当前版本完整跑通，从第 1 篇开始；如果要复核公式或实现约定，按后四篇的主题进入。面向开发者的[3D 前端渲染](frontend-rendering.md)已移到“开发者 › 技术参考”。
